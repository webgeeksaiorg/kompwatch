# How Do I Tell If a Competitor Change Actually Matters?

**Short answer:** Ask three questions in order — which page changed, what specifically changed, and is this part of a pattern. Most changes fail the first question and can be ignored. The ones that pass all three deserve immediate attention.

---

## The 60-Second Triage

### Question 1: Which page changed?

Page type is your fastest filter. Changes on these pages warrant attention:

| Page | Signal level |
|---|---|
| `/pricing` | Highest — pricing changes affect every live sales conversation |
| `/features` or `/product` | High — new capability or removed claim |
| `/alternatives` or `/vs/[your-product]` | High — active repositioning against you |
| Changelog or "What's New" | Medium — useful for pattern, noise individually |
| `/careers` | Medium-High as a leading indicator (what they're building in 6 months) |
| Homepage hero copy | Medium — repositioning signal, not urgent |
| Blog | Low — usually marketing, not strategy |
| Footer, legal, team page | Ignore |

If the change is on a blog, a case study, or a layout element — stop here. Not worth your time.

### Question 2: What specifically changed?

"Pricing page changed" isn't information. Read the diff.

**Low-value pricing page changes:**
- Reformatted the layout (same information, new visual treatment)
- Updated the FAQ section without changing actual prices
- Changed currency display or formatting

**High-value pricing page changes:**
- Dropped or raised a price
- Added, removed, or renamed a tier
- Changed feature access between tiers (something moved up-tier or down-tier)
- Free tier added, capped harder, or removed
- Annual discount changed
- "Contact us for pricing" replaced a listed number (or vice versa)

The same logic applies to feature pages: copy tweaks are noise; new capability claims or removed feature bullets are signal.

### Question 3: Is this part of a pattern?

A single change is a data point. A pattern is a strategy.

Look at what KompWatch has flagged for this competitor over the last 4–6 weeks. If you see:

- Three pricing page changes in six weeks → pricing experimentation or repositioning underway
- Careers page + feature page + pricing page all changing in the same period → strategic initiative in motion
- `/vs/[you]` page getting more specific about your weaknesses → preparing for head-to-head in sales

Context from prior changes is often the difference between "hm, interesting" and "we need to respond to this."

## The Severity Badge as a Shortcut

KompWatch assigns every change a severity level (Low / Medium / High / Critical) using AI. This is a useful starting point:

- **Low** — usually cosmetic; check quickly and move on
- **Medium** — review in your weekly digest cycle
- **High** — read today; decide if it needs a response
- **Critical** — act within 24 hours

The severity badge is calibrated for page type and content. A pricing change on a pricing page will almost always score High or Critical. A layout change on the same page will score Low.

If a change seems more (or less) important than its badge suggests, use the three-question test above to make your own call — the AI can miss context you have about the competitive landscape.

---

## What "Matters" Looks Like in Practice

Changes that have affected sales outcomes for KompWatch users:

- Competitor kills free tier → user's free-vs-paid talking point disappears overnight; win rate goes up because the comparison shifted
- Competitor adds a new $49/mo "Starter" plan → user's AE learns from prospect mid-demo; no prepared response
- Competitor's `/vs/[us]` page suddenly gets a table specifically calling out snapshot frequency → they're actively losing that objection in sales

In each case, the change mattered because it affected *what prospects saw and asked about in live conversations*. That's the test: if a prospect saw this change before your next demo, would it affect the conversation?
