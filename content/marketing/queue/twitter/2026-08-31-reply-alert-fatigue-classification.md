Alert fatigue is a real problem with website monitoring.

First version of KompWatch emailed on every HTML change. CSS comment updated? Alert. Cookie banner tweak? Alert.

Nobody reads that. It trains you to ignore it.

Now it classifies: PRICING / FEATURE / MESSAGING / COSMETIC. Only the first three trigger emails.

Signal vs noise is a product decision, not a configuration option.
